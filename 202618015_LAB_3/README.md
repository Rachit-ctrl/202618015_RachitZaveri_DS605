# Hotel Booking Cancellation Prediction

# This project uses the **Hotel Booking Demand dataset** to predict whether a hotel booking will be canceled using Scikit-learn classification models. The project compares two preprocessing approaches — **StandardScaler** and **MinMaxScaler** — combined with **KNN imputation** and categorical encoding.

# Two classification algorithms, **Logistic Regression** and **Decision Tree**, are trained and evaluated using accuracy, precision, recall, and F1-score. The results show that the **Decision Tree achieved the best overall performance with 86.12% test accuracy and 81.32% F1-score**, while StandardScaler performed slightly better than MinMaxScaler for Logistic Regression.

# The project also analyzes missing values, data leakage, outliers, model overfitting, and confusion matrices to compare the four model-pipeline combinations.
